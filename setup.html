Uppdatera Kilokampens databas

Tar ungefär två minuter. Görs när Claude ber om det. Fotbollsappens data rörs inte: Kilokampen får egna tabeller som alla börjar med kk_.

  1. Kopiera texten.

  2. Öppna Supabase (samma projekt som fotbollsappen) och logga in om det behövs. Öppna SQL Editor
  3. Klistra in texten i den stora rutan och tryck Run. Det ska stå "Success".
  4. Klart. Öppna Kilokampen igen. Texten går bra att köra flera gånger, inget som redan är sparat försvinner.

Fungerar inte kopieringen? Markera allt i rutan här och kopiera själv.
